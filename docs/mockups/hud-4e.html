D&D 4e HUD: three layouts (mockup)

Bottom bar for your own character (the GM's shows the selected token). HP (black line = bloodied, thin blue line = temporary HP), healing surges, defences (green = raised by an effect, red = lowered), speed, Action Points (click to spend: +1 standard action), the action dock (the new Action Tracker: standard, move, minor, immediate, opportunity; dashed = not usable now, struck = spent) and powers in tabs by action type, coloured by usage, greyed when used. Clicking a power uses it as the sheet does. Example character and data are made up.
