Token Reactions (Fable)

A study for "token reactions": when a creature is hit, its token art reacts like a physical coin on the table instead of a projectile flying at it. Each damage type throws the token in its own way, and every hit is rolled afresh (strike point, angle, flips, spin, bounces), so no two look the same. Only the drawing moves; the token itself stays on its square and the art always comes back to it.

Drag the knight or the ogre to another square. Hits come from the knight, so where it stands decides which way the ogre is thrown.
